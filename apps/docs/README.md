# Docs app

Future home for the StateKit documentation website.

## Branding

When this app is scaffolded, wire branding assets from the monorepo root:

| Need | Source | Destination |
| --- | --- | --- |
| Favicon | `../../assets/branding/favicon.svg` | `public/favicon.svg` |
| Open Graph image | `../../assets/branding/og-image.png` | referenced as the default `og:image` |
| Logo (light surfaces) | `../../assets/branding/logo-light.svg` | site header |
| Logo (dark surfaces) | `../../assets/branding/logo-dark.svg` | dark header / hero |

See `docs/branding.md` for usage rules.
